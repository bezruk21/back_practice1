## 📖 Опис проєкту
 Бекенд для проекту веб-сторінки притулку для тварин
---

## ✨ Основні можливості (Features)
* 🔐 **JWT Authentication** — надійна реєстрація та авторизація користувачів.
* 🚀 **Asynchronous CRUD** — висока продуктивність завдяки асинхронності FastAPI та Beanie.
* 💾 **ODM Integration** — зручна робота з MongoDB через Pydantic-моделі.
* 🧪 **Full Test Coverage** — автоматизовані тести для стабільності коду.
* 📑 **Auto-docs** — інтерактивна документація Swagger UI.
